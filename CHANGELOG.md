# История версий

Нумерация: `основная.функции.исправления`. Публичные версии закрепляются тегами `v…` и сохраняют исходные файлы сборки.

## 0.7.1 · 5 ноября 2026

- Панель «Найти / Заменить»: поля 30 pt/px, компактные кнопки, переключатели и фокус в стиле Studio.
- Desktop: поиск локализован на русский/английский, цвета совпадений следуют выбранной палитре.
- Список вкладок: текущая строка выделена, счётчик результатов, понятное пустое состояние; Desktop показывает путь второй строкой.
- Mac: исправлено размещение короткого списка внизу окна — результаты начинаются под поиском; задан минимальный размер окна.

## 0.7.0 · 5 ноября 2026

- Studio UI, одинаковая высота верхних/нижних кнопок и исправление лишнего номера строки.
- 28 уникальных палитр + Studio; выбор в нижней панели, фильтрация по светлой/тёмной/системной теме.
- JSON/SQL по команде, выделение/документ, одно Undo, фоновые вычисления только на время команды.
- SQL/PostgreSQL/MySQL; сохранение записи чисел JSON; ограничения объёма и понятные ошибки.
- Язык интерфейса и диалект SQL в настройках.
- Actions оставляет установщики двух последних стабильных версий, старые исходники и заметки сохраняются; временные артефакты 7 дней.

## 0.6.0

- Компактные панели, адаптивный footer, русский/английский интерфейс и Telegram.
- Поиск среди всех вкладок; проверен сценарий 120 документов на обоих клиентах.

- Windows x64 (NSIS) и Linux x64 (AppImage/deb), отдельный Electron/CodeMirror клиент.
- Вкладки, Unicode-кодировки, атомарное сохранение, сессии, SQL/ksqlDB и split preview.
- Матрица сборок трёх ОС; Release после успеха всех задач, SHA256 каждого пакета.
- ROADMAP, HANDOFF, PLATFORM_TESTING и AGENTS.md для продолжения на другой машине.
- Windows/Linux: проверка GitHub с ручной установкой; мобильные клиенты пока в плане.

## 0.5.0

- Цельные вкладки, выровненные крестики и скруглённые кнопки.
- Область номеров строк вместо NSRulerView, компактный статус и длинные пути без наложений.
- Единый стиль README и GIF реального предпросмотра.

## 0.4.0

- Живой предпросмотр Markdown и HTML справа, изменяемая ширина панелей, ⌥⌘P.
- Офлайн-рендеринг Markdown; изолированный просмотр без скриптов и внешних ресурсов.

## [0.3.0](https://github.com/starscream001/notepad_for_mac/releases/tag/v0.3.0) · 4 ноября 2026

### Добавлено

- Проверка обновлений на GitHub при запуске, по расписанию и вручную.
- Настройки периодичности: 6 часов, сутки, неделя; отключение автоматической проверки.
- Загрузка с прогрессом и отменой, SHA-256, проверка пакета, отдельный установщик, резервная копия и откат.
- Перезапуск с восстановлением вкладок и несохранённого текста.
- Авторство Ильи (starscream001) и ссылка на репозиторий в окне «О программе».
- Окно поддержки с СБП, Ozon Банк и копированием номера.
- Русскоязычное пояснение MIT и добровольной поддержки.
