# История версий

## Mobile 0.10.0-beta.2 · 6 ноября 2026

- «Авто» открывает список форматов; явная кнопка «Меню», команды Undo/Redo, поиск и список заметок доступны без серых заглушек.
- Выбор Markdown/HTML/текста для просмотра, независимо от расширения имени; явный возврат в редактор.
- Android adjustResize и расчёт доступной высоты под клавиатурой на планшете.
- Реальный GitHub Device Flow через системный браузер, Android Keystore/AES-GCM / iOS Keychain, подтверждённое создание приватного репозитория и ручной совместимый sync без force push.
- Native bridge logging выключен; токены не входят в сессии и экспорт заметок.

## Mobile 0.10.0-beta.1 · отдельный prerelease

- Capacitor/CodeMirror для Android, iPhone/iPad и планшетов: проекты, вкладки, локальный журнал сохранения, поиск и подсветка.
- Markdown/HTML preview, RU/EN и светлая/тёмная тема; UTF-8 импорт и системный экспорт/backup.
- Android debug APK и iOS Simulator через отдельный CI. Мобильная синхронизация и TestFlight ещё не подключены.

## 0.9.4 · 5 ноября 2026

- Mac: ошибки синхронизации содержат безопасный HTTP-код и этап запроса. 403/404 больше не выдаются за обычный сбой сети.
- Отдельные подсказки для недоступного репозитория, прав Contents read/write, истёкшего входа, пустой ветки, лимита GitHub и отклонённого обновления. При ошибке доступа раскрываются параметры подключения.
- Токены, содержимое ответов и заметок в диагностику не включаются. Ошибки сети показывают только числовой код.

## 0.9.3 · 5 ноября 2026

- Восстановлены стили Desktop после повреждения CSS в 0.9.2; сборка теперь проверяет CSS через esbuild.

- Удаление проектов вместе с открытыми/закрытыми заметками после подтверждения. Внешние файлы не удаляются; перед действием сохраняется резервная копия сессии.
- Удаление последней заметки и закрытие последней вкладки оставляют проект пустым, без автоматически созданной следующей заметки. Свободные номера используются повторно внутри проекта.
- Корзина доступна у закрытых заметок в боковой панели. Закрытие по крестику сохраняет заметку и её имя.
- Синхронизация передаёт удаление проектов; конкурентно изменённые заметки сохраняются в «Без проекта» как конфликтные копии.
- Все команды GitHub находятся в «Синхронизация → GitHub»; параметры подключения свёрнуты, дублирующие кнопки профиля/проверки входа убраны из интерфейса.

## 0.9.2 · 5 ноября 2026

- Возвращена лиса в toolbar Mac, размер 36 pt; PNG включён в bundle.
- Компактный заголовок проектов с отдельным плюсом вместо большой кнопки, единые отступы заметок и выделение текущей.
- Фиксированы размеры/горизонтальная компрессия команд, overlay scrollbar вкладок; branding Desktop не скрывается вместе с названием.
- Синхронизация и локальные заметки не изменены.

## 0.9.1 · 5 ноября 2026

- Реальная отправка/загрузка в private GitHub repo через Git Data API; отдельная кнопка, подтверждение и один commit, без force push.
- Общий Swift/JS merge, конфликтные копии, явное сквозное удаление через tombstones. Закрытие вкладки сохраняет локальную заметку и не удаляет её в облаке.
- Закрытые заметки остаются в проектах и открываются повторно. Локальные backups перед sync/delete; пути и токены не экспортируются.
- Flat custom controls Mac, одинаковая высота вкладки/плюса, компактные панели и прокрутка настроек.
- Предел sync: 300 заметок, 100 проектов, 1 MiB на заметку, 5 MiB snapshot. Автоматического sync и E2EE нет.

## 0.9.0 · 5 ноября 2026

- GitHub App Device Flow, защищённое хранение, профиль и выход. Вход проверен владельцем на Mac.
- Создание приватного репозитория после явного подтверждения в настройках; никаких автоматических повторов при неизвестном результате запроса.
- Компактные icon-кнопки справа на Mac, предотвращено скрытие команд в узком окне; отделена панель проектов.
- Синхронизация заметок ещё не подключена. Создание репозитория требует разрешения Repository creation у GitHub App.


Нумерация: `основная.функции.исправления`. Публичные версии закрепляются тегами `v…` и сохраняют исходные файлы сборки.

## В разработке · GitHub sign-in для 0.9

- Подготовлен вход через браузер (GitHub OAuth Device Flow) для macOS и Desktop: код, ожидание, отмена, профиль, проверка подключения и выход; русский/английский интерфейс.
- Только read:user; без доступа к репозиториям/синхронизации. Токен в Keychain или safeStorage; Linux plaintext fallback запрещён, renderer и сессия токен не получают.
- Проверяются интервал/slow_down, срок кода, отмена и поздние ответы; секрет приложения и backend не нужны.
- Ожидает публичного Client ID зарегистрированной владельцем OAuth App и реального end-to-end QA. Опубликованная версия остаётся 0.8.0; новые установщики пока не выпускаются.
