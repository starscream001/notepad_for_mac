# Notepad Mobile · 0.10.0-beta.1

Одна мобильная оболочка для Android, iPhone, iPad и Android-планшетов. Capacitor 8 + CodeMirror, без Electron, серверов, аналитики и фоновых индексаторов. Десктопные клиенты остаются самостоятельными.

## Установить для проверки

[Мобильный prerelease](https://github.com/starscream001/notepad_for_mac/releases/tag/mobile-v0.10.0-beta.1).

- **Android 7.0+**: скачайте `Notepad-Mobile-0.10.0-beta.1-Android-debug.apk`, откройте на телефоне и разрешите установку для выбранного файлового менеджера, если Android спросит. Это тестовый debug APK, не версия Google Play. Проверьте SHA256 рядом с файлом.
- **iPhone/iPad (iOS 16+)**: ZIP с пометкой **iOS-Simulator** работает только в симуляторе Xcode на Mac. На iPhone такой ZIP не устанавливается. Для физического устройства откройте проект в Xcode и выберите свой Team; TestFlight пока не настроен.

APK использует тестовую подпись CI. Между сборками она может измениться; Android тогда не сможет обновить приложение поверх старой beta. **Экспортируйте резервную копию перед переустановкой**, иначе удаление приложения удалит его локальные заметки. Постоянная подпись и TestFlight — следующий этап после проверки первой beta.

## Что работает

Проекты, собственные вкладки, закрытие с сохранением заметки, отдельное удаление с подтверждением, свободные номера в каждом проекте. Локальное автосохранение, восстановление текста/курсора, две чередующиеся копии сессии и отдельная копия перед удалением. На телефоне проекты раскрываются слева; на планшете видны постоянно.

Подсветка Markdown/HTML/SQL/Kafka/JSON/JS/Python/CSS. Поиск, светлая/тёмная тема, русский/английский интерфейс. Markdown/HTML-просмотр без скриптов и внешних ресурсов: на телефоне переключение, на планшете рядом с редактором.

Открытие UTF-8 текста до 1 МБ через системный выбор файла, экспорт через системное «Поделиться / Сохранить в Файлы». Резервная копия всех заметок — переносимый JSON до 5 МБ; импорт добавляет копии, не перезаписывая имеющиеся заметки. Можно импортировать `.notepad/snapshot.json` десктопной синхронизации, предварительно скачав файл вручную. Это **импорт**, не автоматическая синхронизация.

## Пока отсутствует

GitHub-вход и синхронизация мобильного клиента, редактирование внешнего файла на месте, фоновая синхронизация, UTF-16 и публикация в магазинах. Мобильный клиент не берёт токены из десктопа. Сессия хранится в sandbox приложения. Не выдавать браузерную проверку за тест физической клавиатуры, экранной клавиатуры или сохранения при принудительной выгрузке ОС.

## Собрать

Node.js 22+, `npm ci`, `npm test`, `npm run build` в этой папке. `npm run dev` — браузерный preview на `http://127.0.0.1:4175`; это не отдельный опубликованный сайт и не PWA.

Android: Android SDK 36 + JDK 21, затем `node scripts/prepare.mjs android` и `cd android && ./gradlew assembleDebug` (`gradlew.bat assembleDebug` на Windows). APK в `android/app/build/outputs/apk/debug/`.

iOS: полный Xcode 26+ на Mac. `node scripts/prepare.mjs ios`, затем `npm run ios`. В Xcode выбрать Team и подключённое устройство. Для симулятора подпись не нужна. Для TestFlight потребуется аккаунт Apple Developer и настройка App Store Connect владельцем.

Нативные папки генерируются из **зафиксированного package-lock.json**, не коммитятся. Скрипт выставляет версию, лису, iOS privacy manifest и семейство iPhone/iPad. После изменения web-кода выполните `npm run build`, затем prepare для своей платформы. Общие модули берутся из `../Resources/SyncCore.js` и `../desktop/src/preview.js`.

CI: `.github/workflows/mobile.yml`, отдельные APK / iOS-Simulator artifacts, затем отдельный prerelease `mobile-v…`. Стабильный desktop-релиз не заменяется мобильной beta. APK и ZIP не хранятся в Git.
