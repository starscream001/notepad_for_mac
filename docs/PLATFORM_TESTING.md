# Проверка приложения на другой платформе

## Быстрый старт без отладчика

Windows: скачать `Notepad-Desktop-<версия>-Windows-x64-Setup.exe` из GitHub Release, запустить установку для текущего пользователя. После установки открыть Notepad Desktop из меню «Пуск».

Linux: скачать `.AppImage`, в свойствах разрешить выполнение или выполнить `chmod +x Notepad-Desktop-*-Linux-x64.AppImage`, затем запустить. Если система сообщает об отсутствии FUSE, можно использовать `--appimage-extract-and-run` или установить `.deb` через менеджер пакетов на Debian/Ubuntu. Не запускать редактор с `sudo`.

Для работы готовой сборки Node.js и компилятор не нужны. Для разработки: Node.js 24 LTS, `cd desktop`, `npm ci`, `npm test`, `npm start`.

## Изолированный запуск исходников

PowerShell:

```powershell
$env:NOTEPAD_DESKTOP_DATA = Join-Path $env:TEMP "notepad-smoke"
cd desktop
npm ci
npm test
npm start
```

Linux:

```sh
cd desktop
npm ci
npm test
NOTEPAD_DESKTOP_DATA="$PWD/../work-session" npm start
```

Если нужно диагностировать запуск, сохранить вывод терминала. Для более сложного дефекта следующим шагом можно подключить Electron DevTools, но первый проход не требует отладчика.

## Проверено при подготовке 0.6

Русский/английский интерфейс нативного клиента переключён в обе стороны без потери открытых документов.
