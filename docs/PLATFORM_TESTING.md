# Проверка приложения на другой платформе

## Быстрый старт без отладчика

Windows: скачать `Notepad-Desktop-<версия>-Windows-x64-Setup.exe` из GitHub Release, запустить установку для текущего пользователя. После установки открыть Notepad Desktop из меню «Пуск».

Linux: скачать `.AppImage`, в свойствах разрешить выполнение или выполнить `chmod +x Notepad-Desktop-*-Linux-x64.AppImage`, затем запустить. Если система сообщает об отсутствии FUSE, можно использовать `--appimage-extract-and-run` или установить `.deb` через менеджер пакетов на Debian/Ubuntu. Не запускать редактор с `sudo`.

Для работы готовой сборки Node.js и компилятор не нужны. Для разработки: Node.js 24 LTS, `cd desktop`, `npm ci`, `npm test`, `npm start`.

## Изолированный запуск исходников

PowerShell:

```powershell
$env:NOTEPAD_DESKTOP_DATA = Join-Path $env:TEMP "notepad-smoke"
cd desktop
npm ci
npm test
npm start
```

Linux:

```sh
cd desktop
npm ci
npm test
NOTEPAD_DESKTOP_DATA="$PWD/../work-session" npm start
```

Если нужно диагностировать запуск, сохранить вывод терминала. Для более сложного дефекта следующим шагом можно подключить Electron DevTools, но первый проход не требует отладчика.

## Обязательные сценарии

- [ ] Установка и первый запуск стандартным пользователем, без прав администратора.
- [ ] Новый документ: русский текст, emoji, SQL; сохранить в путь с пробелами и кириллицей.
- [ ] Все кодировки: UTF-8, UTF-8 BOM, UTF-16 LE/BE; LF/CRLF/CR. Повторно открыть, проверить текст.
- [ ] Открыть 10 вкладок, длинное имя, переключение клавиатурой, горизонтальный скролл, крестики.
- [ ] Изменить документ, закрыть вкладку: проверить Сохранить/Отмена/Не сохранять.
- [ ] Оставить несохранённый текст и курсор, завершить всё приложение, запустить: восстановление.
- [ ] Изменить файл другой программой, попытаться сохранить: предупреждение о конфликте.
- [ ] Поиск/замена и регулярное выражение; Undo/Redo после замены.
- [ ] SQL и ksqlDB: строковые литералы, комментарии, ключевые слова, ручной выбор языка.
- [ ] `examples/preview.md` и `preview.html`: редактор слева, просмотр справа, ввод и изменение ширины мышью/стрелками.
- [ ] HTML со `<script>alert(1)</script>` и удалённой картинкой: скрипт не выполняется, ресурс не загружается.
- [ ] Светлая/тёмная/системная темы, окно 800×480, DPI 100/150/200%, нет наложения текста.
- [ ] Офлайн запуск, ручная проверка обновлений: понятный результат, работа не блокируется.
- [ ] Автор/репозиторий/дорожная карта открываются; номер доната копируется правильно.
- [ ] Повторная установка новой версии сохраняет сессию; удаление приложения не уничтожает пользовательские документы.
