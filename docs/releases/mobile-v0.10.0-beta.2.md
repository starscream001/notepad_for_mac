# Notepad Mobile 0.10.0-beta.2 · Android 14 и GitHub

- **«Авто»** теперь открывает отдельный удобный список форматов и подсветки. Системный select для него убран.
- **«Меню»** видно в верхней панели. Добавлены Undo/Redo и список всех заметок; поиск, переименование, файлы и backup доступны в одном месте. Для отсутствующей заметки показывается объяснение вместо молча отключённой кнопки.
- **«Просмотр»** предлагает Markdown, HTML или текст/код даже у заметки без расширения. На телефоне — отдельный экран с кнопкой «Редактор», на планшете — соседняя панель. Скрипты и внешние ресурсы HTML заблокированы.
- **Клавиатура Android:** задан adjustResize, высота интерфейса учитывает viewport/клавиатуру без двойного вычитания; редактор сохраняет свою прокрутку.
- **Меню → GitHub:** настоящий вход через системный браузер и Device Flow, создание приватного репозитория после подтверждения и ручная синхронизация с desktop. Нужен доступ App к выбранному приватному репозиторию с Contents read/write. Передача заметок требует отдельного подтверждения. Закрытые заметки сохраняются, явное удаление и конфликты совместимы с desktop.
- Доступ хранится в **Android Keystore/AES-GCM** и **iOS Keychain**. Нет токенов в сессиях/backup, native bridge logging выключен. Сервер разработчика не требуется.

## Скачать и обновить

**Android:** `Notepad-Mobile-0.10.0-beta.2-Android-debug.apk` — телефон и планшет. SHA256 рядом. Это тестовая debug-подпись: перед удалением старой beta экспортируйте все заметки. Если Android отклонит установку поверх beta.1 из-за подписи, установите новую beta после экспорта и удаления старой, затем импортируйте backup.

**iPhone/iPad:** `Notepad-Mobile-0.10.0-beta.2-iOS-Simulator.zip` — для симулятора Xcode. Для физического устройства нужен проект и подпись своей Personal Team/Team в Xcode; TestFlight пока не настроен.

## Проверки

16 unit-тестов модели, входа/отмены/защищённого хранения, merge и расчёта клавиатуры. CI собирает Android и iOS Simulator; Android 14 tablet emulator проверяет нажатие формата/просмотра, доступность команд, native Keystore и отсутствие перекрытия нижней панели экранной клавиатурой. Настоящий вход в аккаунт и двухустройственную синхронизацию пользователь проверяет после установки; агент не извлекал токены владельца. Эмулятор не заменяет проверку конкретного телефона/клавиатуры.
