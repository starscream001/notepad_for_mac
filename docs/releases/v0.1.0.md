# Первая версия Notepad Mac

Нативный текстовый редактор для macOS с верхними вкладками, вдохновлённый Notepad++.

### В этой версии

- Вкладки с именами файлов, отметкой изменений, кнопкой «+» и закрытием через ⌘W.
- Базовая подсветка кода и разметки: Swift, JavaScript, TypeScript, Python, JSON, HTML/XML, CSS, C/C++, Markdown, Shell и YAML.
- Поиск и замена, регулярные выражения, учёт регистра и отмена изменений.
- Номера строк, переход к строке, автоотступы и перенос строк.
- UTF-8, UTF-8 BOM, UTF-16 LE/BE с BOM; LF, CRLF и CR.
- Системная, светлая и тёмная темы, изменение размера шрифта.
- Восстановление вкладок и несохранённого текста после перезапуска.
- Предупреждение перед перезаписью файла, изменённого другой программой.

### Установка

Скачайте **Notepad-Mac-universal.zip** в разделе **Assets**, распакуйте и перенесите **Notepad Mac.app** в «Программы».

**Требования:** macOS 13+, Intel или Apple Silicon. Приложение имеет ad-hoc подпись. При блокировке первого запуска: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
