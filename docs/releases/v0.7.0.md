# Notepad 0.7.0 · Studio, палитры и форматирование

## Что нового

- Оформление Studio (вариант Б): компактные скруглённые кнопки одинаковой высоты, спокойные вкладки и согласованная нижняя панель.
- Выбор палитры **внизу рядом с темой**: все 28 уникальных пар из подборки Алисы, 14 светлых и 14 тёмных, плюс Studio. Светлая/тёмная тема фильтрует список; системная следует ОС. Несовместимая палитра сбрасывается на Studio. Выбор сохраняется.
- Ручное форматирование JSON и SQL: кнопка **Формат**, **⌘/Ctrl+Shift+F**, выделение или весь документ; одно Undo отменяет результат. В фоне при вводе форматирование не запускается.
- JSON сохраняет точную запись больших чисел, экспонент, строк и повторяющихся ключей. Ошибка не заменяет исходный текст.
- Диалекты SQL, PostgreSQL, MySQL в настройках; авто по .psql/.pgsql/.mysql. Для .sql — обычный SQL. ksqlDB форматирование пока не поддерживает; это не серверный линтер.
- Ограничения команды: JSON 1 млн, SQL 50 тыс. единиц UTF-16, глубина JSON до 64. Форматтер SQL/JSON собран отдельно (~92 КБ); в Desktop работает временный Worker, в Mac — системный JavaScriptCore вне главного потока.
- Язык интерфейса Русский/English перенесён в настройки (⚙, ⌘/Ctrl+,).
- Исправлен лишний номер строки у документа без завершающего перевода строки.
- После успешной публикации сохраняются установщики и SHA256 двух последних стабильных версий. Старые теги, исходники и описания остаются. Артефакты новых Actions живут 7 дней.

## Скачать и установить

В **Assets** ниже:

| ОС | Файл |
| --- | --- |
| macOS 13+, Intel / Apple Silicon | **Notepad-Mac-universal.zip** — распаковать, перенести приложение в «Программы» |
| Windows x64 | **Notepad-Desktop-0.7.0-Windows-x64-Setup.exe** — запустить установщик |
| Linux x64 | **Notepad-Desktop-0.7.0-Linux-x64.AppImage** — разрешить выполнение и запустить; либо **.deb** для Debian/Ubuntu |

Рядом SHA256 каждого пакета. **Source code** — исходники, не готовая программа. На Mac с 0.3+ есть установка обновления из приложения; Windows/Linux открывают Release для ручной установки. Платных сертификатов подписи пока нет.

## Проверка и границы

CoreChecks на macOS; Node-тесты файлов, форматирования и безопасной очистки релизов. JSON/SQL, выделение и Undo проверены в живых тестовых окнах на macOS; сборки трёх ОС проверяет CI. Установщики Windows/Linux нужно дополнительно проверить на реальных машинах владельца. Новые палитры не добавляют пакетов или фоновых служб. Проекты и мобильные клиенты пока не реализованы.
