# Notepad 0.9.3 · Управление проектами и заметками

- Восстановлены стили Windows/Linux после ошибки 0.9.2. Сборка теперь проверяет синтаксис CSS.
- Корзины в боковой панели удаляют проект или любую заметку, включая закрытую. Удаление проекта требует подтверждения и удаляет все его заметки; внешние файлы на диске сохраняются.
- Последнюю заметку можно удалить. Пустой проект остаётся пустым — приложение не создаёт следующую заметку автоматически, в том числе после перезапуска.
- Новая заметка получает минимальный свободный номер в своём проекте. Закрытая заметка сохраняется и занимает имя; после удаления номер освобождается.
- Удаление проекта отправляется при ручной синхронизации. Несинхронизированные изменения другого устройства сохраняются конфликтной копией в «Без проекта». Для удаления проектов обновите оба устройства до 0.9.3.
- Все действия GitHub скрыты в «Синхронизация → GitHub». Основная команда — «Синхронизировать»; создание репозитория, разрешение доступа и выход находятся в свёрнутых параметрах подключения.

## Скачать

macOS Intel / Apple Silicon: **Notepad-Mac-universal.zip**. Windows x64: **Notepad-Desktop-0.9.3-Windows-x64-Setup.exe**. Linux x64: **Notepad-Desktop-0.9.3-Linux-x64.AppImage** / **.deb**. SHA256 рядом с каждым установщиком.

## Проверки

CoreChecks и 55 Node-тестов, включая передачу удаления проекта в обе стороны и сохранение конкурентных изменений. UI native Mac и Desktop (Electron на Mac) проверен в отдельных сессиях: удаление последней заметки, повтор номера 1, удаление проекта и раскрытие настроек GitHub. Windows/Linux проходят сборку CI; ручная проверка на этих ОС остаётся отдельным шагом. Реальная двухустройственная синхронизация через аккаунт владельца агентом не выполнялась.
