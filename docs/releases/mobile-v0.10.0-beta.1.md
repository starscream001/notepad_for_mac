# Notepad Mobile 0.10.0-beta.1

Первая отдельная мобильная beta для Android, iPhone/iPad и планшетов. Локальный редактор, без сервера и аккаунта.

- Проекты со своими вкладками; закрытие сохраняет заметку, удаление — отдельно с подтверждением.
- Автосохранение и восстановление, два слота сессии, копия перед удалением.
- Подсветка SQL/Kafka, Markdown/HTML/JSON/JS/Python/CSS; поиск, RU/EN, светлая/тёмная тема.
- На телефоне проекты раскрываются слева. На планшете — постоянная панель и редактор рядом с Markdown/HTML-просмотром.
- UTF-8 импорт и экспорт через системные файлы/«Поделиться», резервная копия всех заметок в JSON. Импорт копий не перезаписывает текущие заметки.

## Установка

**Android 7+**: `Notepad-Mobile-0.10.0-beta.1-Android-debug.apk` — тестовый установщик для телефона и планшета. SHA256 рядом. Это debug beta, не Google Play. Подпись CI может измениться в следующей сборке: перед переустановкой экспортируйте backup, удаление приложения удаляет локальные заметки.

**iPhone/iPad**: `Notepad-Mobile-0.10.0-beta.1-iOS-Simulator.zip` — только для симулятора Xcode на Mac. На физический iPhone ZIP не устанавливается. Для своего устройства: исходники + Xcode26 и выбор Team. TestFlight ещё не настроен.

[Подробная инструкция](https://github.com/starscream001/notepad_for_mac/blob/main/mobile/README.md).

## Ограничения и проверка

Мобильный GitHub-вход и синхронизация пока не подключены. Браузерные проверки не заменяют проверку клавиатуры и сохранения на реальном устройстве. Unit-тесты модели/журнала и CI-компиляция Android/iOS; web UI проверен на телефоне и планшете, включая Markdown и восстановление после перезагрузки.

Это отдельный prerelease: стабильная desktop-версия остаётся в разделе Latest.
