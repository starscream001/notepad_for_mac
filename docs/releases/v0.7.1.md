# Notepad 0.7.1 · Вкладки и поиск

Небольшое обновление оформления поверх [0.7.0](https://github.com/starscream001/notepad_for_mac/releases/tag/v0.7.0).

## Исправлено

- «Найти / Заменить»: поля и кнопки одной компактной высоты, согласованные отступы, состояния переключателей и фокуса в стиле Studio.
- Поиск Desktop использует русский/английский язык интерфейса; найденные фрагменты оформлены в цветах выбранной палитры.
- «Вкладки»: выделена текущая строка, показано количество найденных вкладок, добавлено сообщение при пустом результате. Длинные названия обрезаются; полный путь доступен в подсказке, в Desktop также второй строкой.
- На Mac короткий список вкладок больше не прижимается к низу окна; результаты располагаются сразу под полем поиска. Окно ограничено разумным минимальным размером.

Включает все возможности 0.7: Studio, 28 палитр в нижней панели, ручное JSON/SQL форматирование, обновления и восстановление сессии. Новых зависимостей и фоновых служб в патче нет.

## Скачать

В **Assets**:

- **Mac:** `Notepad-Mac-universal.zip` — распаковать и перенести в «Программы»; macOS 13+, Intel / Apple Silicon.
- **Windows x64:** `Notepad-Desktop-0.7.1-Windows-x64-Setup.exe` — запустить установщик.
- **Linux x64:** `Notepad-Desktop-0.7.1-Linux-x64.AppImage` — разрешить выполнение; либо `.deb` для Debian/Ubuntu.

Рядом SHA256. Source code — исходники. Mac обновляется из приложения; Windows/Linux — вручную через Release. Сертификатов коммерческой подписи пока нет.

Проверено: native CoreChecks, Node-тесты, живой интерфейс Mac и общий Desktop UI на macOS. GitHub Actions собирает три ОС; ручная проверка установщиков на Windows/Linux остаётся отдельным этапом.

Установщики хранятся для двух последних стабильных версий; старые теги, исходники и описания остаются.
