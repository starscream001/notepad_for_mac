# Notepad 0.6.0 · Windows и Linux

Теперь в одном выпуске доступны три десктопные платформы:

| Платформа | Что скачивать |
| --- | --- |
| macOS 13+, Intel / Apple Silicon | **Notepad-Mac-universal.zip** |
| Windows x64 | **Notepad-Desktop-0.6.0-Windows-x64-Setup.exe** |
| Linux x64 | **Notepad-Desktop-0.6.0-Linux-x64.AppImage** или **.deb** |

Все пакеты находятся ниже, в **Assets**. `Source code` — исходники, не готовое приложение. Рядом с каждым пакетом есть SHA256.

## Что нового

- Windows/Linux клиент на Electron + CodeMirror: вкладки, поиск/замена с regex, подсветка SQL и Kafka/ksqlDB, Markdown, HTML, JavaScript/TypeScript, Python, JSON, CSS.
- Предпросмотр Markdown/HTML справа, изменение ширины мышью и клавиатурой; скрипты документа и внешние ресурсы отключены.
- UTF-8/BOM, UTF-16 LE/BE, LF/CRLF/CR; атомарное сохранение, предупреждение о внешнем изменении файла.
- Восстановление несохранённых вкладок, курсора и выбора языка после выхода.
- Светлая/тёмная/системная темы, ссылки на автора, поддержка через СБП.
- Сборки Windows/Linux/macOS в GitHub Actions; публикация только после успеха всех сборок.
- [Дорожная карта](https://github.com/starscream001/notepad_for_mac/blob/main/docs/ROADMAP.md), [передача работы](https://github.com/starscream001/notepad_for_mac/blob/main/docs/HANDOFF.md) и [чек-лист проверки на ОС](https://github.com/starscream001/notepad_for_mac/blob/main/docs/PLATFORM_TESTING.md).

## Установка и обновление

**Mac:** распаковать ZIP, перенести приложение в «Программы». С 0.3+ работает обновление из приложения.

**Windows:** запустить Setup EXE, установить для текущего пользователя. Подписанного сертификата пока нет; возможен запрос SmartScreen.

**Linux:** разрешить выполнение AppImage и запустить. Если нет FUSE — `--appimage-extract-and-run` или пакет `.deb` для Debian/Ubuntu.

**Windows/Linux:** проверка GitHub при запуске, по расписанию или по кнопке; установка новой версии пока вручную из Release. Не выполняется автоматическая замена работающего приложения.

## Статус первой поддержки платформ

Пакеты проходят автоматическую сборку и тесты на GitHub runners Windows/Linux. Общий клиент дополнительно проверен в живом окне на macOS: редактор, Markdown preview и восстановление несохранённого текста. Ручная проверка установщиков и поведения на машинах владельца Windows/Linux ещё предстоит; результат фиксируется отдельно от CI.

Нативный Mac-клиент сохранён. Сессии Mac и Desktop независимы; список языков и отдельные настройки пока различаются. iPhone/iPad/Android ещё не реализованы, этапы описаны в дорожной карте.
