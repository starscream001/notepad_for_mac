# Notepad 0.9 · GitHub и приватное хранилище

- Вход через GitHub в браузере, короткий код, профиль, проверка входа и выход. Токен хранится защищённо, не в сессии/renderer.
- Если App ещё не установлено: «Разрешить доступ GitHub» открывает официальную установку. Затем Настройки → GitHub → Создать приватный репозиторий. Требуется отдельное подтверждение. Создаётся private repo с README, заметки не отправляются.
- GitHub App должен иметь Repository creation write; владельцы организаций могут ограничивать установку. Для всех пользователей используется одно публичное приложение Notepad Desktop, создавать свои GitHub Apps не нужно.
- Mac: компактные команды справа, предотвращено автоматическое скрытие кнопок в узком окне, визуально отделена панель проектов.

## Установка

macOS: Notepad-Mac-universal.zip. Windows: Notepad-Desktop-0.9.0-Windows-x64-Setup.exe. Linux: Notepad-Desktop-0.9.0-Linux-x64.AppImage / .deb. Рядом SHA256. Mac и Windows 0.7.3+ обновляются из приложения, Linux вручную.

## Границы

Синхронизация заметок пока в разработке: этот выпуск содержит вход и создание хранилища. Не заявляет успешную отправку проектов. При ошибке/тайм-ауте создания сначала проверить список репозиториев GitHub; существующие репозитории не перезаписываются. Вход на Mac подтверждён владельцем; создание repo проверено mock-тестами, реальный проход и Windows/Linux QA ещё нужны. Нет платных сертификатов подписи.
