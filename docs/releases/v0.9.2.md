# Notepad 0.9.2 · Лиса и ровная компоновка

- Лиса вернулась в верхнюю панель Mac, увеличена до 36 pt. Ресурс включён в готовое приложение.
- Компактный заголовок «Проекты» и отдельная кнопка +; заметки выровнены с одинаковым отступом. Текущая заметка выделена спокойным фоном.
- Высота вкладок и кнопок фиксирована, команды не растягиваются по горизонтали. Overlay-прокрутка не отнимает высоту вкладок.
- Desktop сохраняет лису даже когда подпись бренда скрывается в узком окне.

Синхронизация, локальное сохранение и сквозное удаление из 0.9.1 сохранены. «Сохранить» — локально, GitHub — отдельной кнопкой, крестик закрывает, корзина удаляет после подтверждения.

## Скачать

macOS Intel / Apple Silicon: Notepad-Mac-universal.zip. Windows x64: Notepad-Desktop-0.9.2-Windows-x64-Setup.exe. Linux x64: Notepad-Desktop-0.9.2-Linux-x64.AppImage / .deb. SHA256 рядом с каждым пакетом.

CoreChecks и 54 Node-теста; компоновка native Mac проверена в изолированных QA-сборках, включая узкое окно 860 pt. Windows/Linux: сборки CI, ручной DPI QA остаётся необходимым.
