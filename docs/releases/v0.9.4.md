# Notepad 0.9.4 · Понятные ошибки синхронизации на Mac

Вместо общего сообщения «проверьте сеть, приватность и права» Mac показывает **HTTP-код и этап запроса**. Сообщение различает недоступный репозиторий (404), запрет доступа (403), истёкший вход (401), пустую ветку, лимит запросов и отказ обновления ветки. Параметры подключения раскрываются при ошибке доступа.

Для доступа GitHub App должна быть установлена на выбранный приватный репозиторий и иметь **Contents: Read and write**. Вход в аккаунт сам по себе этого не подтверждает. После изменения прав GitHub может запросить их принятие.

Диагностика не содержит токенов, заметок или тел ответов GitHub. Локальные заметки остаются сохранены. Причина конкретного сбоя определяется по новому HTTP-коду; этот выпуск не утверждает, что права аккаунта владельца проверены агентом.
