# Notepad 0.9.1 · Заметки в GitHub

Теперь «Синхронизировать» действительно отправляет заметки в приватный репозиторий и загружает их на другом устройстве.

- Отдельная кнопка GitHub. «Сохранить» остаётся локальным действием. Отправка всех проектов/заметок только по ручной команде и после подтверждения.
- Крестик закрывает вкладку: заметка сохраняется локально в проекте и открывается снова.
- Корзина с подтверждением удаляет заметку локально; следующий sync переносит удаление в облако и на другие устройства. Внешние файлы не удаляются; Git history сохраняет прошлые версии.
- Конфликт сохраняет обе версии, включая изменение одновременно с удалением. Ветка обновляется без force; гонка с другим устройством требует повтора.
- Компактные ровные кнопки/вкладки Mac и прокручиваемые настройки.

## Подключить

Настройки → GitHub → Войти. При необходимости «Разрешить доступ GitHub», затем создать private repo с README или указать существующий в своём аккаунте. Имя по умолчанию notepad-notes. Нажать «Синхронизировать»; на другом устройстве выбрать тот же repo. Организации и public repo пока не поддержаны.

## Скачать

Mac Intel/Apple Silicon: Notepad-Mac-universal.zip. Windows x64: Notepad-Desktop-0.9.1-Windows-x64-Setup.exe. Linux x64: Notepad-Desktop-0.9.1-Linux-x64.AppImage / .deb. SHA256 рядом с пакетами.

## Ограничения и проверка

До 300 заметок, 100 проектов, 1 MiB UTF-8 на заметку и 5 MiB snapshot. Данные в .notepad/snapshot.json, не E2EE. Нет фонового sync. Expired GitHub access требует повторного входа. Перед sync/delete локальная резервная копия сессии.

54 Node-теста и CoreChecks, включая JavaScriptCore merge, первый upload/download, tombstones и гонку ветки; нативный UI закрытия/восстановления проверен на Mac. Реальный двухустройственный сценарий с аккаунтом владельца и ручной Windows/Linux QA ещё требуют проверки — mocked API не выдаётся за реальный GitHub E2E.
