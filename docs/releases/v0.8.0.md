# Notepad 0.8 · Проекты и собственные вкладки

Рабочие заметки теперь можно разделять на независимые проекты: слева проекты и их документы, сверху — вкладки выбранного проекта. Без дерева файлов и фонового индексирования.

- **«+ Проект»** → «Проект 1» → «Заметка 1». У каждого проекта своя нумерация и последняя выбранная вкладка.
- Заголовки **Работа.План**. Двойное нажатие переименовывает проект/вкладку; файлы на диске от этого не переименовываются.
- Панель можно скрыть. Прежние документы находятся в **«Без проекта»**; перед миграцией создаётся `session.before-projects.json`.
- Несохранённый текст и курсор остаются в пользовательских данных вне папки приложения; **«Сохранить как»** экспортирует документ в выбранное место.
- Исправлен HTML-предпросмотр: собственный встроенный CSS, атрибуты html/body, Grid, таблицы и формы как макет. Проверены таблицы, списки, цитаты и блоки кода Markdown. Скрипты и внешние ресурсы по-прежнему запрещены.
- Уменьшены `+` и шестерёнка; исправлена ширина редактора с боковой панелью на Mac.

## Скачать и обновить

| Платформа | Файл в Assets |
| --- | --- |
| macOS 13+, Intel / Apple Silicon | **Notepad-Mac-universal.zip** |
| Windows x64 | **Notepad-Desktop-0.8.0-Windows-x64-Setup.exe** |
| Linux x64 | **Notepad-Desktop-0.8.0-Linux-x64.AppImage** или **.deb** |

Mac и Windows начиная с 0.7.3 устанавливают обновление из приложения; старый Windows-клиент обновляется вручную один раз. Linux — вручную. SHA256 рядом с каждым пакетом. Установщики сохраняются для двух последних стабильных версий; теги, исходники и описания остаются.

## Проверка

CoreChecks и 31 Node-тест: кодировки, сессии, проекты, форматирование, updater. Нативный и общий Desktop-интерфейсы проверены на macOS с отдельными тестовыми сессиями: создание/переключение, переименование, сохранение текста, Markdown/HTML. Пакеты всех трёх ОС собираются в CI; ручные установка и DPI-проверка Windows/Linux остаются по [чек-листу](https://github.com/starscream001/notepad_for_mac/blob/main/docs/PLATFORM_TESTING.md).
