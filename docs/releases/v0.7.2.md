# Notepad 0.7.2 · О проекте и светлые схемы

- **«О проекте»** снова отдельной кнопкой в верхней панели: автор, GitHub и Telegram.
- **Настройки** перенесены в нижнюю панель (⚙). Внутри — язык интерфейса и диалект SQL; параметры текущего документа остаются внизу.
- В светлой теме **основной текст и подписи чёрные (#000000), фон всегда белый (#FFFFFF)**; цвет меняется у кнопок и активной вкладки. Персик и остальные цветные фоны убраны.
- Светлые схемы: **Бумага · Небесный · Белый и красный**. Тёмные: прежние **14 схем без изменений**. В обеих темах доступна Studio. Сокращён только светлый список.

Включает исправления вкладок/поиска из 0.7.1 и все возможности 0.7: 17 палитр + Studio, ручное JSON/SQL форматирование, сессии и Markdown/HTML preview. Новых зависимостей в патче нет.

## Скачать

В Assets ниже:

| ОС | Файл |
| --- | --- |
| macOS 13+, Intel / Apple Silicon | **Notepad-Mac-universal.zip** — распаковать, перенести в «Программы» |
| Windows x64 | **Notepad-Desktop-0.7.2-Windows-x64-Setup.exe** — запустить установщик |
| Linux x64 | **Notepad-Desktop-0.7.2-Linux-x64.AppImage** — разрешить выполнение; либо **.deb** для Debian/Ubuntu |

Рядом SHA256 каждого пакета. Source code — исходники. Mac обновляется из приложения, Windows/Linux — через скачанный пакет. Коммерческих сертификатов подписи пока нет.

Проверки: CoreChecks macOS, 22 Node-теста, сборки трёх ОС в Actions. Ручная проверка установщиков Windows/Linux на реальных машинах остаётся отдельным этапом.

Установщики хранятся для двух последних стабильных версий; старые теги, исходники и описания остаются.
