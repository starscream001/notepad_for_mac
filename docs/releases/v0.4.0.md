# Notepad Mac 0.4.0 · Редактируйте и сразу смотрите результат

- Предпросмотр Markdown и HTML справа от редактора: кнопка **«Просмотр»**, меню **Вид** или **⌥⌘P**.
- Обновление при вводе с короткой задержкой, без сохранения файла и без интернета.
- Изменяемая ширина панелей, таблицы, списки, цитаты и блоки кода Markdown (Marked 18.1.3, MIT).
- Для новой вкладки выберите язык **Markdown** или **HTML / XML**. Для файлов `.md`, `.markdown`, `.html`, `.htm` формат определяется автоматически.
- Скрипты, формы, удалённые ресурсы и доступ к локальным файлам из предпросмотра отключены. Встроенные CSS и data-изображения поддерживаются. HTTP(S)-ссылки открываются во внешнем браузере.
- Предпросмотр ограничен 2 МБ; более крупные документы можно редактировать.

## Установка

Скачайте **Notepad-Mac-universal.zip**, распакуйте и переместите **Notepad Mac.app** в «Программы». Подходит для Intel и Apple Silicon, macOS 13+.
Из версии 0.3 можно обновиться через **Notepad Mac → Проверить обновления…**. Сессия сохраняется перед заменой.
