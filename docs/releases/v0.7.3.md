# Notepad 0.7.3 · Обновление Windows внутри приложения

Windows больше не требует открывать GitHub для каждого обновления:

- «Помощь → Проверить обновления» или «О проекте → Проверить сейчас»; проверка при запуске/по расписанию.
- «Скачать обновление»: загрузка внутри редактора, прогресс, отмена и проверка размера/SHA256.
- «Установить и перезапустить»: сохранение вкладок и несохранённого текста, повторная проверка файла и запуск обычного мастера Windows. После завершения мастера новая версия запускается с прежней сессией.
- Повреждённые/незавершённые загрузки удаляются; при ошибке сохранения или запуска установщика редактор остаётся открыт.
- Новых зависимостей и фоновых служб нет. Проверки Windows/SmartScreen не обходятся; Authenticode-подписи пока нет.

**Важно: с 0.7.2 и старше на 0.7.3 нужно перейти вручную один раз.** Старый updater не содержит новой логики. После этого следующие обновления Windows скачиваются из приложения.

## Скачать

| ОС | Файл из Assets |
| --- | --- |
| Windows x64 | **Notepad-Desktop-0.7.3-Windows-x64-Setup.exe** — запустить поверх старой версии в прежнюю папку |
| macOS 13+, Intel / Apple Silicon | **Notepad-Mac-universal.zip** — распаковать в «Программы», либо обновить из приложения |
| Linux x64 | **Notepad-Desktop-0.7.3-Linux-x64.AppImage** или **.deb** — пока устанавливаются вручную |

Рядом SHA256 каждого файла; Source code — исходники. Linux updater этим патчем не изменён. Mac продолжает использовать свой updater. Сохраняются установщики двух последних стабильных версий, старые теги/исходники/описания остаются.

## Проверка и ограничения

CoreChecks macOS, 28 Node-тестов, сборки macOS/Windows/Linux в CI. Автотесты проверяют повреждение файла, прерванную загрузку, отмену, чужие redirects и запрет запуска при ошибке сохранения. Реальные установка/перезапуск NSIS на Windows требуют ручного прохода на машине владельца. Автоматического отката NSIS в этом выпуске нет.
