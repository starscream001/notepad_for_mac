# Обновления Notepad Mac

Начиная с версии **0.3.0**, приложение проверяет стабильные выпуски в GitHub Releases и может установить новую версию с перезапуском.

## Как проверить

- **Вручную:** меню **Notepad Mac → Проверить обновления…**.
- **Автоматически:** при запуске, возвращении в приложение и по таймеру, если подошёл выбранный срок и есть сеть.
- **Настройки:** **Notepad Mac → Настройки обновлений…**. По умолчанию — раз в сутки. Доступны 6 часов, сутки, неделя и отключение автоматической проверки.

Без интернета редактор продолжает работать. Автоматическая проверка не показывает сетевые ошибки; ручная объясняет причину. После ошибки запрос повторяется не раньше чем через 15 минут. Ручная проверка доступна в любой момент, даже при отключённой автоматической.

## Установка новой версии

1. Приложение сообщает о новой версии. Можно установить её, отложить или открыть описание на GitHub.
2. **«Скачать и установить»** загружает архив с GitHub. Окно показывает ход загрузки; её можно отменить.
3. Редактор проверяет размер и SHA-256 по метаданным GitHub, содержимое ZIP, идентификатор приложения, версию, минимальную macOS, архитектуру и подпись пакета.
4. Перед выходом сохраняется сессия со всеми вкладками и несохранённым текстом.
5. Отдельный установщик ждёт завершения редактора, готовит новую копию в папке установки и сохраняет предыдущую версию рядом.
6. Новое приложение запускается и подтверждает успешный запуск. После этого предыдущая копия удаляется. При ошибке замены или запуска установщик восстанавливает прежнюю версию.

Если новая версия остаётся запущенной, но не подтверждает старт в течение минуты, резервная копия сохраняется, а установщик сообщает её путь. Диалоги macOS не обходятся автоматически.

## Требования

Запускайте приложение из доступной для записи папки — обычно **«Программы»**. Если папка доступна только администратору или приложение работает из защищённого временного расположения macOS, редактор предложит ручную установку через Finder. Повышенные права и пароль администратора установщик не запрашивает.

Для первого перехода с **0.1 / 0.2 на 0.3** скачайте приложение [из релиза](https://github.com/starscream001/notepad_for_mac/releases/latest) и замените его вручную. Проверка и установка будущих версий доступны уже в 0.3.

## Какие данные используются

Проверка обращается к публичному API `api.github.com` для репозитория `starscream001/notepad_for_mac`. Загрузка идёт с GitHub и его серверов release-assets. Токен GitHub и вход в аккаунт не нужны. Текст открытых файлов, номер СБП и содержимое сессии в запросы обновлений не включаются.

Контрольная сумма берётся из поля `digest` публичного GitHub API через HTTPS. Подпись текущих сборок ad-hoc: она проверяет целостность пакета, а доверенным источником обновления остаётся указанный GitHub-репозиторий. Это не подпись Apple Developer ID и не нотариальное заверение Apple.

Рабочие файлы установщика находятся в `~/Library/Application Support/NotepadMac/Updates/`. Сессия хранится отдельно в `~/Library/Application Support/NotepadMac/session.json`.
